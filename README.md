# MEA_piccolo
Data and drafts for MEA spring 2024 meeting 

This project focuses on how changes in land affected by the Endangered Species Act impacts residential mobility in Michigan.

This repository is primarily to organize my workflow for this project. Some files are too big (demographic data), and others are restricted use (NatureServe). Therefore, this project is not reproducible from the files in this repository alone. 

The general workflow goes as follows:
1. Stage one prep for both time periods (2000-2010, 2010-2020)
2. Mobility sorting model for both time periods
   - This is the second stage and regresses the mean utilities found in the first stage

Data: 
- The percent of land dedicated to protected habitat was found using NatureServe, a non-profit organization that provides wildlife conservation-related data, tools, and services to private and government clients, partner organizations, and the public.
- The remainder of the data used in this project was collected from publicly available sources, including the decennial census, the American Community Survey, Google Maps, and Zillow.
